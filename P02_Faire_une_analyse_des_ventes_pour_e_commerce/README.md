# 🏥 Réaliser une analyse des ventes pour une entreprise de Ecommerce – Le Grand marché

Bienvenue sur la page consacrée au projet **Réaliser une analyse des ventes pour une entreprise de Ecommerce**. 

Ce projet illustre mes compétences en **Analyse et visualisation de données** à travers une étude des résultats commerciaux d'une entreprise.

Pour mener à bien ce projet j'ai :

* Exploré et visualisé les données avec Excel
* Calculé des indicateurs clés
* Afficher les résultats dans un tableau de bord Excel et les indicateurs sous forme de graphiques.
* Présenter oralement les résultats en choisissant les visualisations les plus pertinentes tout en paratiquant le storytelling

---

## 📊 Contexte

L'entreprise **Le Grand Marché** spécialisé dans le Ecommerce souhaite avoir une analyse mensuelle de ces résulats commerciaux, afin d'identifier des axes d'améliorations pour dynamiser sa croissance.

---

## 🎯 Objectif

 Présenter les résultats mensuels et proposer des axes d'améliorations en :

- Identifiant les visualisations les plus pertinentes
- Analysant les résulats des ventes des différentes catégories de produits
- Visualisant l'évolution de plusieurs indicateurs ( taux de conversion, Nombre de ventes...)
- Présentant  les résultats de manière claire et compréhensible
